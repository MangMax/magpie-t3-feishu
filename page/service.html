使用已有机器人 · 手动配置
还没有配置机器人？按这份清单操作
  1. 在飞书开发者后台创建企业自建应用，添加「机器人」能力。
  2. 事件与回调选择「长连接」，订阅 im.message.receive_v1。
  3. 开通 im:message.p2p_msg:readonly 和 im:message:send_as_bot。
  4. 发布应用版本，将自己加入应用可用范围。

若飞书要求先建立长连接，再保存事件订阅，可先完成下面的绑定并启用桥接，然后回飞书保存订阅、发布版本。

App Secret 以本机文件权限保护的明文保存，不上传给 T3，也不是系统钥匙串加密。

第三步

绑定你的工作区

推荐独立项目，也可选已有会话。已有绑定不会改变。

手动配置与 ID 获取方法

你的飞书 open_id：它以 ou_ 开头，而且必须属于上一步的同一个飞书应用，不是手机号或 union_id。可在该应用的 API 调试台使用「通过手机号或邮箱获取用户 ID」，使用同一应用的 tenant_access_token，只在飞书调试台使用此 token，不要粘贴到本插件。设置 user_id_type=open_id，优先用自己的手机号查询（此接口不支持企业邮箱）。复制响应 data.user_list[].user_id 中的值：字段名仍叫 user_id，值应以 ou_ 开头。

该查询需要 contact:user.id:readonly 权限及覆盖本人的数据权限；没有权限请向应用管理员获取自己的 open_id。本插件不申请或修改这些权限，也暂不自动发现用户。

T3 线程 ID：在 Magpie 对话中要求：「调用 T3 的 t3_thread_list（allProjects: true），列出线程标题、threadId 和 environmentId，不要发送消息或改动线程。」复制结果中你要使用的 threadId。建议选择一个专用线程，不要粘贴线程标题或整个页面网址。

远程线程若同时返回 environmentId，再填到该绑定的高级设置中；没有就留空，不要猜测或粘贴环境名称。

飞书 IM 专用工作区

创建飞书 IM 独立项目

创建独立命名项目、Git 目录和会话。需要 T3 MCP Full Access 授权；不会自动提升权限或启动模型。

创建范围与恢复说明

使用蓝色「飞」字标（不是飞书品牌 Logo），可在 T3 手动更换。目录由 T3 管理，不承诺自动清理或永久保留。结果未知时只核验或续办原请求，不重复创建。创建后仍需保存绑定。

最后一步

检查并启用

保存后，给机器人发一条私聊完成验证。

启用前核对

    启用后，可信用户的私聊文字会让绑定的 T3 线程执行任务。仅绑定你信任的账号；审批仍需回到 T3 处理。

    发送第一条消息

    1. 点击保存，查看下方飞书连接状态。
    2. 在飞书找到你的机器人，发一条私聊文字，例如「请告诉我当前项目名称，不要修改文件」。
    3. 等待该轮结束后的文字回复；同时在 T3 核对对应线程。

    只支持私聊文字，不支持群聊、图片、语音；不是逐字流式回复。Magpie 插件宿主退出后，桥接也会停止。
